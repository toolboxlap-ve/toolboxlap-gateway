# TOOLBOXLAP Gateway — GMI Edition v0.2.8

## Release summary

v0.2.8 is the current published Windows release of the local Anthropic-compatible gateway for GMI Cloud. It maps a Claude-visible alias to a selected GMI model and has been tested with `MiniMaxAI/MiniMax-M3`.

## Published artifact

- Filename: `TOOLBOXLAP-Gateway-GMI-0.2.8.exe`
- Platform: Windows x64 portable executable
- Size: 99,610,811 bytes
- SHA-256: `BF5F5A1EA740FE9575789E9E845A07C8035983E4E073313E0C38CECE0E2643EF`
- Authenticode status: not signed

Verify the checksum before running the executable. Windows SmartScreen may warn because the file does not have a public Authenticode signature.

## Major features

- Local gateway at `127.0.0.1:8787` by default
- GMI API-key connection testing
- GMI model discovery and selection
- Default Claude-visible alias `claude-opus-5`
- Tested upstream target `MiniMaxAI/MiniMax-M3`
- Streaming message forwarding
- Anthropic-style tool definition and tool-use passthrough
- Local activity and request statistics with sensitive fields excluded
- Electron renderer isolation and allowlisted external links

## Setup summary

1. Launch the executable.
2. Enter and save a GMI API key.
3. Test the connection.
4. Fetch and select a model.
5. Start the gateway.
6. Configure Claude with `http://127.0.0.1:8787`, bearer authentication, the displayed Local Gateway Token, and model discovery.

## Security notes

- Keep the default loopback bind unless there is a specific advanced need.
- The public `toolboxlap` Local Gateway Token is a convenience value and is not strong protection for network exposure.
- Never expose a GMI-backed gateway directly to the public Internet.
- The public-release candidate source adds a fail-closed strong-token requirement for non-loopback binding. That hardening changes packaged bytes and must not be assumed to be present in the published artifact solely because both identify as v0.2.8.
- The GMI API key is encrypted with Electron `safeStorage` when available. A plaintext user-data fallback is possible when platform encryption is unavailable.

## Known limitations

- Windows x64 only.
- The executable is not Authenticode-signed.
- Provider/model compatibility can change upstream.
- MCP and tool behavior depends on the selected model's capabilities.
- Detailed historical changes between v0.2.7 and the originally published v0.2.8 artifact are unavailable in the retained source copy.
